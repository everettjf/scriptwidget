1 · Set up once

Give your Agent the widget toolkit.

Mac CLI + Skill: Install the CLI for local checks and automatic preview, then copy its bundled Skill into Claude Code. The CLI requires macOS 26 or later and runs natively on Apple Silicon.

brew install everettjf/tap/scriptwidget-cli
mkdir -p ~/.claude/skills
# First install: keep existing customized Skills safe.
test ! -e ~/.claude/skills/scriptwidget-creator && cp -R "$(brew --prefix scriptwidget-cli)/libexec/ScriptWidgetCLI.app/Contents/Resources/scriptwidget-creator" ~/.claude/skills/

Already installed? Run brew upgrade scriptwidget-cli, back up any custom Skill edits, and refresh your copied folder. Skill only: Without Homebrew, unzip the Skill download and copy the entire scriptwidget-creator folder into ~/.claude/skills/. A project can use .claude/skills/ instead. The Skill provides instructions to your Agent; CLI commands require the separate Mac CLI installation.

2 · Create and inspect

Your idea, already in the preview.

/scriptwidget-creator Create a medium reading habit widget and open its Web Studio preview.

The Agent checks your package with scriptwidget check and opens it with scriptwidget preview.

The browser opens with your widget loaded as a new project, preserving your existing work. Package content travels in the URL fragment and is cleared from the address bar before import. It is not uploaded to an inference or storage server. Treat preview links as private: they contain your code and resources. Links support up to 45 KB of compressed package data; larger packages can use native previews or explicit .swt import.

Web previews use mock data and approximate platform rendering. For native macOS light/dark PNGs, ask the Agent to run scriptwidget render ./MyWidget --output ./artifacts --format json.

3 · Take it to iPhone

Preview, export, make it yours.

Export a .swt from Web Studio or the CLI. Send it through AirDrop or iCloud Drive, or open Studio on iPhone and share the file to ScriptWidget. Review permissions, then add a ScriptWidget widget to the Home Screen and choose your imported package. The Skill does not install the iOS app or place Home Screen widgets automatically.
