# Privacy Review

Review the requested widget before generating or editing code:

- Minimize permissions and data collection.
- Keep credentials out of source, prompts, logs, parameters, and widget storage.
- Declare every network host and explain why it is needed.
- Prefer offline behavior when it meets the requirement.
- Provide a useful fallback when remote or private data is unavailable.
- Do not invent runtime APIs or claim privacy guarantees the code cannot enforce.
