ScriptWidget lets users create native widgets with JavaScript and JSX. This update turns AI generation into a conversation about one widget: the user describes a widget or a change, the reply is run on the device, and nothing is saved or applied until the user chooses to. AI is optional: it runs only when the user opens it and sends a request. The provider is chosen in Settings > AI: Apple Private Cloud Compute by default where available, or the user's own key for Anthropic or an OpenAI-compatible server, stored in the Keychain. The request and the widget's code go only to the provider the user chose. A generated widget that uses the network asks the user to allow the hosts it names before it is saved. No login is required for built-in local templates. Review can start with New Widget > any template (for example Daily Affirmation or Datetime Current), then Preview. Calendar, Reminders, Photos, Location and Health templates use explicit user-selected sources and system access where supported. The interface is in English. The App/Share extension supports iOS 16+, the Widget extension requires iOS 18+, and the macOS app and widget require macOS 26+.
